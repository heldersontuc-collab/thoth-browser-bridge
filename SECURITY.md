# Seguranca

- Nenhuma chave privada deve ser commitada.
- Nenhum segredo deve aparecer em issues, commits, logs ou nomes de arquivo.
- A API interna do THOTH Browser continua privada na rede Docker.
- Senhas, OTP, cartao, PIX, compra e transferencia permanecem humanas.
- O Bridge deve ignorar forks, PRs e branches diferentes de main.
- Resultados devem expirar automaticamente.
- A VPS deve manter a chave privada fora do repositorio.
